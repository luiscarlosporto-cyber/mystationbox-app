# mystationbox · app

Ecrã da aplicação mystationbox (gestão de caixa da estação de serviço), publicado no GitHub Pages.
Só contém a página: os dados ficam na cloud (Supabase), protegidos por login e regras de acesso.
O código-fonte completo e a documentação estão no repositório privado `mystationbox` (pasta `app/`).
